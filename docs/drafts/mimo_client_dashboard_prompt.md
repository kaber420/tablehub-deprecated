# Tarea: Desarrollar ClientDashboard.svelte

Actúa como un desarrollador frontend experto y crea el panel FINAL para el cliente del restaurante en `cloud/web/src/pages/ClientDashboard.svelte`.

## Requisitos de la interfaz
1. **Glassmorphism y Estética Premium**: El panel debe verse increíble. Usa efectos translúcidos (backdrop-filter), sombras suaves, fuentes modernas y gradientes de color que le den un toque "vivo" al dashboard.
2. **KPIs del Cliente**:
   - Muestra tarjetas para: "Hubs Activos", "Dispositivos IoT", "Sucursales" y "Sesiones de App".
   - Por ahora usa datos mockeados o hardcodeados (ej. 3 Hubs, 15 Dispositivos) pero prepara el diseño para que se vea robusto.
3. **Acciones Rápidas**:
   - Agrega botones grandes o tarjetas que permitan navegar rápidamente a: "Mis Hubs", "Mi Equipo", "Facturación".
4. **Diseño Responsivo**: Asegúrate de usar grid o flexbox para que se adapte perfectamente a diferentes pantallas.

Haz que el diseño sea lo más moderno posible, evitando colores planos aburridos. Usa microanimaciones (hover, transiciones).

Reemplaza por completo el contenido actual de `cloud/web/src/pages/ClientDashboard.svelte` con tu nueva implementación.
